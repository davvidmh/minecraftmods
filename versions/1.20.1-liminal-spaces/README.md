# Minecraft 1.20.1 (Forge - Liminal Spaces / Backrooms Oficial)

El pack oficial de Liminal Spaces (The Backrooms) desarrollado por Designio. Incluye el mod oficial de 67 bloques liminales en ultra-resolución 512x con modelos 3D, texturas PBR LabPBR completas, optimización con Embeddium + Oculus, y configuración personalizada para trazado de rayos con SEUS PTGI HRR 3.
